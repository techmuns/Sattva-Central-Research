# Manager visual identities

Public artwork catalogue; presence here does not assert an investment or Family membership.
No workbook values, accounts or private source rows are included. Brand names and aliases
are used only to select an image for an authenticated, in-memory card.

Artwork retrieved on 14 October 2026, fitted without stretching to 160 × 160 WebP
canvases for 44px thumbnails. Exfinity's white wordmark keeps a dark canvas.
Source owners retain their marks. Disruptors uses its masthead wordmark (its site's
favicon was a browser screenshot). HDFC's mark is published by AMFI; the Julius Baer
vector is the publisher's annual-report mark reproduced on Wikimedia Commons.

Aliases preserve workbook spelling and fund/series suffixes; they do not rename or
merge investments. Matrix Partners India is now [Z47](https://www.z47.com/legal/fund-details);
[veda.vc](https://veda.vc/) redirects to Shastra VC. LC Nueva uses the mark of its
[co-manager Lighthouse Canton](https://www.lighthouse-canton.com/our-businesses/asset-management/private-market-funds/lc-nueva-fund/).
The explicitly named Kettleborough–Nisarg syndicate uses Kettleborough's mark;
Innergize (Blue Ashva) uses Blue Ashva's mark. The in-house card reuses Sattva's existing
brand asset. Unknown names and failed images use the dashboard's gradient initials.
